정기멤버십 정책

1. 결제 정책
  • 결제 주기: 매월 자동 결제되며, 가입일 기준으로 고정됩니다.
  • 결제 실패 시: 1일 후 1회만 자동으로 재시도합니다.
  • 재시도까지 실패하면 최종실패로 처리되며, 이후 자동 재시도는 없습니다(다음 결제 주기에도 재시도하지 않습니다).
  • 결제 금액 변경 시: 기존 가입자는 기존 금액을 유지하며, 변경된 금액은 신규 가입자부터 적용됩니다.
  • 가입 시 정기결제 동의(카드 등록·인증)가 카드사 거절 등으로 실패하면 가입이 완료되지 않으며, 실패 사유를 보여주고 다시 시도하거나 가입 없이 종료할 수 있습니다.
  • 등록된 카드가 만료되었거나 정기결제에 실패한 상태에서 이용현황 화면에 재진입하면 결제 수단 확인 안내와 결제 수단 변경 진입점이 노출됩니다.
2. 결제상태값 정의
상태값의미
결제완료정상적으로 결제되었습니다.
재시도중1차 실패 후 1일 뒤 재시도를 대기하거나 진행 중입니다.
최종실패재시도까지 실패하여 결제가 종료되었습니다.
3. 이용상태값 정의
상태값의미관리 버튼
이용중정상적으로 이용 중입니다.해지
해지예정해지가 신청되어 다음 결제일까지 이용이 유지됩니다.-
해지완료이용이 종료되었습니다.-
4. 해지 정책
  • 해지를 신청해도 즉시 해지되지 않으며, 다음 결제일까지 이용이 유지된 후 자동으로 해지됩니다.
  • 해지취소 기능은 제공하지 않습니다(되돌릴 수 없으며, 해지 버튼 클릭 시 확인 팝업으로 다시 확인합니다).
  • 해지 후 재이용은 재가입으로만 가능하며, 첫 달 프로모션 등 별도 혜택은 제공하지 않습니다.
  • 해지 시 환불은 불가합니다.
  • 일시정지 기능은 제공하지 않습니다.
  • 해지예정 상태의 회원이 이용현황 화면에 재진입하면 해지 버튼과 결제 수단 변경 진입점 대신 해지 예약 안내 문구가 노출됩니다.
5. PG 연동 관련
  • PG 심사를 위해 "숨김" 상태의 테스트 상품 1개를 등록해야 하며, 등록 전에는 연동하기 버튼이 비활성화됩니다.
  • 연동하기를 눌러도 즉시 연동되지 않으며, PG사 심사가 진행되는 동안 연동 상태는 "심사중"으로 표시됩니다.
  • 연동 상태는 미연동 · 심사중 · 반려 · 연동됨 4단계로 관리됩니다. 반려되면 반려 사유가 함께 노출되고, 연동하기를 다시 눌러 재심사를 요청할 수 있습니다.
  • PG 연동을 해제하면 신규 가입이 중단되고, 기존 회원은 이미 결제된 기간까지만 이용할 수 있습니다.
  • 연동 해제 후 재연동하면 기존 멤버십 설정(가격, 혜택 등)이 초기화되며, 이때 확인 팝업이 노출됩니다.
6. 혜택/상품 정책
  • 혜택은 정기멤버십 전용 상품으로 지정된 상품에만 적용되며, 지정된 상품이 없으면 혜택이 적용되지 않습니다.
  • 전용 상품을 삭제하면 전용 상품 목록에서도 함께 삭제됩니다.
  • 전용 상품 유형은 공통판매(전체 노출)와 멤버십 전용(비회원 구매 불가) 두 가지이며, 상품별 전용가는 별도로 설정하지 않습니다.
  • 정기멤버십 전용상품 지정은 상품 등록/수정 화면(개별 지정)과 정기멤버십 전용 상품 관리 화면(일괄 지정 및 전체 현황 확인) 양쪽에서 가능하며, 두 화면은 동일한 값을 공유합니다.
  • 비회원 또는 멤버십 미가입 회원이 멤버십 전용 상품을 클릭하면 상품 상세 대신 안내 팝업이 노출되며, 정기멤버십 가입 화면으로 연결됩니다.
  • 지정된 전용 상품이 하나도 없으면 정기멤버십 전용 상품 관리 화면과 멤버십 전용상품 리스트 화면 모두 목록 대신 빈 상태 안내가 노출됩니다.
7. 기타 정책
  • 멤버십은 판매자당 하나만 설정할 수 있는 단일 멤버십 구조이며, 여러 등급을 추가로 만들 수 없습니다.
  • 회원이 쇼핑몰을 탈퇴하면 가입 중인 멤버십은 자동으로 해지됩니다.
  • 멤버십 사용 여부를 끄면 PG 연동 해제와 동일하게 처리되며, 이때 확인 팝업이 노출됩니다.
  • 정기멤버십 가입완료·해지·결제 최종실패 시 알림톡이 자동으로 발송되며, 메시지 > 알림톡 설정에서 템플릿을 관리합니다.
  • 정산은 별도 화면 없이 기존 매출 탭에 합산되어 반영됩니다.
  • 이미 가입한 회원이 정기멤버십 소개 페이지에 재진입하면 가입 버튼과 약관 동의 영역 대신 이용 중 안내 문구가 노출됩니다.
  • 정기멤버십 가입자 관리 화면은 검색 조건에 맞는 가입자가 없을 때와 최초로 가입자가 한 명도 없을 때를 구분해 서로 다른 빈 상태 안내를 보여줍니다.
